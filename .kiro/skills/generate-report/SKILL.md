# 매출 보고서 생성

data-2025.csv 데이터를 분석하여 Word 보고서(.docx)를 생성합니다.
Steering의 "보고서 양식" 규칙을 반드시 따릅니다.

## 실행 단계

[1] 데이터 읽기: public/data-2025.csv 파일을 읽고 분석합니다.
[2] 보고서 생성: docx 라이브러리를 사용하여 Word 문서를 생성합니다.
[3] 저장: public/reports/ 폴더에 저장합니다.

## 보고서 구성

파일명: 매출보고서_YYYY-QN.docx

### 헤더

- 로고: assets/logo.svg 파일을 좌측 상단에 삽입
- 문서 제목: Steering 보고서 양식 규칙의 제목 형식을 따름
- 작성일: 생성 시점 날짜

### 본문 구성

1. 요약 (Steering 규칙: 3줄 이내)
   - 총 매출액, 총 고객수, 평균 성장률, 제품별 비중
2. 지역별 현황 표 (지역, 매출액, 고객수, 성장률)
   - Steering 규칙: 합계 행 포함
3. 월별 추이 설명 (Steering 규칙: 한 문장 요약)
4. 추천 액션 (데이터 기반 개선 제안 3개)

### 푸터

- 페이지 번호

## 사용법

"이번 분기 보고서 만들어주세요" → 가장 최근 분기 데이터로 보고서 생성
"2025년 연간 보고서 만들어주세요" → 전체 데이터 합산 보고서
