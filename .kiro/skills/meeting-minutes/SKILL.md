# 회의록 정리

STT(음성→텍스트) 변환된 회의 텍스트를 읽고 구조화된 회의록을 대시보드 페이지로 표시합니다.

## 실행 단계

[1] 텍스트 읽기: 지정된 STT 텍스트 파일을 읽습니다.
[2] 분석: 참석자, 안건, 발언 내용을 파악합니다.
[3] 구조화: 회의록 양식에 맞게 정리합니다.
[4] 대시보드 표시: MeetingMinutesPage 컴포넌트로 렌더링합니다.

## 회의록 양식

대시보드 경로: 사이드 네비게이션 > 회의록 (📝)

### 헤더

- 페이지 제목: "회의록"
- 회의 주제를 description으로 표시

### 본문 구성

1. 회의 정보 (일시, 장소, 참석자 뱃지, 주제)
2. 안건별 논의 내용 (ExpandableSection으로 접기/펼치기)
3. 결정 사항 (✅ StatusIndicator로 표시)
4. 액션 아이템 (담당자, 기한 포함 테이블)
5. 다음 회의 일정

### 푸터

- "작성자: AI 자동 생성 | 검토 필요"

## 정리 규칙

- "어...", "그래서...", "음..." 등 필러 제거
- 반복되는 내용 통합
- 발언자별로 핵심 의견만 추출
- 결정 사항과 액션 아이템은 명확하게 분리
- 기한이 언급되면 날짜로 변환

## 데이터 소스

- public/meeting-stt.txt 파일을 fetch로 로드
- parseMeetingSTT() 함수로 구조화

## 사용법

"meeting-stt.txt 회의록 정리해주세요" → 대시보드 회의록 페이지에서 확인
