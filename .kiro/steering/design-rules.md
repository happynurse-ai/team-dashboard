# 디자인 규칙

## 브랜드 컬러

### 주요 팔레트
| 용도 | 색상 코드 | 설명 |
|------|-----------|------|
| Primary | `#FF9900` | 브랜드 오렌지 — CTA 버튼, 강조 요소 |
| Primary Dark | `#EC7211` | 호버/액티브 상태 |
| Secondary | `#232F3E` | 다크 네이비 — 헤더, 사이드바 배경 |
| Accent Blue | `#0972D3` | 링크, 차트 기본색 |
| Accent Teal | `#44B9D6` | 보조 차트색, 배지 |
| Success | `#037F0C` | 긍정 지표, 성장률 양수 |
| Warning | `#D91515` | 경고, 성장률 음수 |
| Neutral 100 | `#FAFAFA` | 페이지 배경 (라이트 모드) |
| Neutral 800 | `#0F1B2A` | 페이지 배경 (다크 모드) |

### 다크 모드 차트 색상
- 기본: `#539FE5`, 보조: `#89D2DC`, `#A4B0BE`, `#EB8F6A`, `#8CC665`

### 라이트 모드 차트 색상
- 기본: `#0972D3`, 보조: `#44B9D6`, `#7D8998`, `#E07941`, `#69AE34`

## UI 컴포넌트
- CloudScape Design System 컴포넌트만 사용합니다.
- 기본 HTML 태그(div, span 등)로 UI를 만들지 않습니다.
- 차트 라이브러리는 Recharts를 사용합니다.

## 헤더
- 모든 페이지 상단에 Header 컴포넌트를 배치합니다.
- 대시보드 헤더에는 필터/액션 버튼을 actions 영역에 배치합니다.

## 카드
- 카드 레이아웃은 3열 그리드를 기본으로 합니다.
- KPI 카드는 4열 그리드로 배치합니다.
- 모든 카드에 그림자(box-shadow)와 둥근 모서리(border-radius: 12px)를 적용합니다.
- 카드 호버 시 위로 살짝 올라가는 애니메이션을 적용합니다.

## 보고서 양식 규칙

### 제목 형식
- 보고서 제목: `[팀명] YYYY년 N분기 매출 보고서`
- 대시보드 페이지 제목: `매출 분석 대시보드`

### 구성 요소 (순서 준수)
1. **요약 KPI** — 총 매출액, 총 고객수, 평균 성장률, 제품 수를 상단에 카드로 표시
2. **추이 차트** — 월별 매출액(Bar) + 성장률(Line) 복합 차트
3. **비교 차트** — 지역별 매출 비교(Bar) + 비중(Pie) 나란히 배치
4. **상세 테이블** — 전체 데이터를 페이지네이션 + 정렬 가능한 테이블로 표시

### 차트 규칙
- 모든 차트에 범례(Legend)를 포함합니다.
- 금액 축은 `억` 단위로 포맷합니다 (예: `1.5억`).
- 퍼센트 축은 `%` 접미사를 붙입니다.
- 툴팁에 정확한 수치와 단위를 표시합니다.
- 차트 높이는 최소 350px을 유지합니다.

### 테이블 규칙
- 숫자 컬럼은 천 단위 콤마를 적용합니다.
- 정렬 가능한 컬럼 헤더를 제공합니다.
- 페이지당 10행, 페이지네이션을 포함합니다.
- 필터 적용 시 건수를 헤더에 `(N)` 형태로 표시합니다.

### 필터
- 기간(월) 필터와 지역 필터를 제공합니다.
- 필터 변경 시 모든 차트와 KPI가 즉시 업데이트됩니다.
- 기본값은 "전체 기간", "전체 지역"입니다.

## 네비게이션
- 사이드 네비게이션에 아이콘(이모지)을 표시합니다.
- 현재 페이지는 하이라이트 표시합니다.
- 페이지 상단에 브레드크럼을 표시합니다.
- 네비게이션 하단에 "© 2026 클라우드 솔루션팀" 텍스트를 표시합니다.

## 푸터
- 모든 페이지 하단에 "© 2026 | Powered by Kiro" 텍스트를 표시합니다.

## 접근성
- 모든 이미지에 alt 텍스트를 제공합니다.
- 색상만으로 정보를 전달하지 않습니다 (패턴/라벨 병행).
- 키보드 네비게이션을 지원합니다.
